# OWASP Top 10 for LLM Applications (2025): Suivo control map

Each risk maps to the controls that implement it in `services/public-ai-svc` and the tests that prove it. Paths are relative to the service directory. Residual items are owned in `docs/suivo/r0-readiness.md`.

| Risk | Controls | Tests |
|---|---|---|
| **LLM01 Prompt injection** (direct and indirect) | Deterministic X06 screen before any model call (`policy/classify.go`). Evidence wrapped in L3-EVIDENCE-001 as DATA and escaped (`model.BuildPrompt`). Poisoned sources quarantined at ingest (`policy.LooksLikeInjection` in `knowledge/ingest.go`). Output gate rejects tool instructions and instruction leaks (`validate`). | `orchestrator/TestInjectionRefusedWithSignal`, `release/TestPrivateAndPoisonedNeverRetrieved`, `validate/TestGatewayDeadlineAndNoTools`, `acceptance/TestG21`, `TestG22`, `TestS07` |
| **LLM02 Sensitive information disclosure** | Redaction detectors (card, IBAN, SSN, NINO, secrets, password, OTP, bank, private identifiers); X03 template never echoes and the text never reaches the model. No raw prompt or output logging (config refuses `PUBLIC_AI_LOG_RAW_PROMPT`). Events carry no chat text. | `policy/TestRedactSensitiveInput`, `TestRedactNoFalsePositives`, `orchestrator/TestSensitiveInputNeverEchoed`, `events/TestEnvelopeShapeAndRedaction`, `config/TestRawPromptLoggingRefused`, `acceptance/TestS08`, `TestS10` |
| **LLM03 Supply chain** | Pinned Go modules (`go mod verify` in CI). Ed25519-signed knowledge and claim releases verified on load. Non-root, read-only container. gitleaks on every PR. Model vendor gated by DEC-05. | `release/TestSignatureEnforced`, CI `ci.yml` and `secret-scan.yml` |
| **LLM04 Data and model poisoning** | Source registry with approval state, licence and private-marker checks. Two-person approval for P1 claims. Revocation watermark ledger (append-only) and re-check at commit. No fine-tuning. | `release/TestIngestionStates`, `TestClaimsValidationRequiresTwoApprovals`, `TestRevocationSurvivesRollback`, `TestRevokedSinceAtCommit`, `orchestrator/TestRevocationMidFlightAbstains` |
| **LLM05 Improper output handling** | Output gate: markup and script refused, model URLs/e-mails/phones stripped, numbers must be grounded, 120-word cap. Links come only from signed route and citation registries (`/config`). The widget renders escaped text only. | `validate/TestCheck`, `TestModelLinksAreRemoved`, `release/TestRoutesRejectUnsafeURLs`, `orchestrator/TestOutputValidation` |
| **LLM06 Excessive agency** | No tools: the gateway never sends a tools array; tool-call drafts are discarded with a security signal. CTAs are route-only, and a click is recorded, not acted on. Role fixed to PUBLIC_ANONYMOUS. No dependency on any private service. | `isolation/TestForbiddenDepsRejectsOtherServices`, `TestSECT049_NoOtherZoikoModules`, `orchestrator/TestDemoIsRouteOnly`, `TestPrivateDataAndActionsRefused`, `acceptance/TestS06` |
| **LLM07 System prompt leakage** | X06 refusal. Validator blocks output naming instructions or prompt layers. Only `model.PromptVersion` (a hash) is logged. | `validate/TestCheck` (instruction leak), `acceptance/TestS07` |
| **LLM08 Vector and embedding weaknesses** | Mandatory filters (audience, approval, validity, market, revocation) applied before ranking. Separate public index with no route to internal collections. No vectors in R0 (ADR-002). | `release/TestPrivateAndPoisonedNeverRetrieved`, `TestExpiredSourceIsStale`, `orchestrator/TestRevokedSourceIsNotUsed` |
| **LLM09 Misinformation** | Price, trial, market, certification and integration facts come only from VERIFIED typed claims, else abstain. Conflicts block. Governed status labels never upgraded. Banned absolutes refused. | `release/TestClaimDecisions`, `orchestrator/TestConflictingPricesAbstain`, `TestSOC2NeverClaimedCertified`, `acceptance/G01–G36`, `TestS04`, `TestS09`, `evalrun` golden set |
| **LLM10 Unbounded consumption** | Per-IP and per-session token buckets, global in-flight cap, daily/monthly token ceilings, one active turn per session, 2,000-char message cap, model timeout and circuit breaker. | `limits/TestPerIPLimit`, `TestPerSessionLimitAcrossIPs`, `TestGlobalInFlightCap`, `TestSpendCeilingStopsAnswering`, `orchestrator/TestProviderFailuresFallBackSafely`, `httpapi/api_test.go` (413, 409) |

## Open items (not provable in code)

- External pen test or equivalent (master prompt §10).
- DPIA screening, processor and region documentation, cookie inventory (DEC-06).
- Egress allowlist and SSRF tests against cloud metadata, once hosting is decided (DEC-01).
